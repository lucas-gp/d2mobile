## Tables derived from Diablo II data (outside the MIT licence)

These files were recreated from the Diablo II data tables as read by the author (gameplay facts and official names/labels), in some cases
supplemented with values from the Project Diablo 2 wiki or from Project Diablo 2's season-13 data tables. **The repository does not place them under MIT**: the MIT licence covers only the code and the structures that are
our own; the names, trademarks and labels remain the property of Blizzard Entertainment, Inc. and are removed upon request from a rights holder (`DISCLAIMER.md`). The
TypeScript files carry the header `SPDX-License-Identifier: LicenseRef-D2-Derived-Data` (non-standard: "data derived from Diablo II, see this file"); the
files that cannot carry a comment are listed here or in an adjacent `LICENSE-DATA.md`.

The generators in `tools/` do not rewrite these headers by hand; if a file is regenerated, put the header back.

Files that **cite** a game table without copying values or names from it (code and isolated facts, MIT, no header): `src/data/rates.ts`
(one value: mana refilled in 120 s, ManaRegen from CharStats.txt), `src/data/monster-attacks.ts` (shape of the attacks; monster skill identifiers
from monstats.txt in a comment), `src/data/zones/d2farm.ts` and `src/data/zones/tombs.ts` (population computed from the Levels.txt columns
read in `levels-a*.ts`), `src/data/items/loot-value.ts` (our own valuation of items, by identifier). `src/ui/credits.ts` is our own credits text: MIT, no header.

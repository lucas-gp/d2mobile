# mods/pd2 — Project Diablo 2 (saison 13)

Mod « refonte » (`kind: 'overhaul'`) : le jeu de règles `pd2`, celui de tous les personnages existants (sauvegardes d'avant la version 7
comprises), actif par défaut. Système de mods : `src/mods/README.md`. Plan de migration : lots M0 à M14 (docs/JOURNAL.md, lots 198 et
suivants).

- `manifest.ts` : chargé au démarrage ; `index.ts` (contenu) est un chunk séparé, chargé à l'activation du jeu de règles.
- Ce dossier ne s'importe jamais depuis le jeu (règle ESLint de frontière) ; son code n'importe du jeu que `src/mods/api` et le moteur `src/mods/sdk` (le manifest : l'API seule), ses tests et outils
  peuvent importer le jeu.
- `MODS=` (vide) construit, teste et lance le jeu sans ce mod ; le test de suppression (`npm run mods:suppression`) le vérifie sur une
  copie du dépôt sans `mods/`. Tests propres au mod : `tests/unit/` (suite `unit`) et `tests/bots/` (suite `bots` : boucle des cartes, progression jusqu'au prérequis des cartes, objectifs calibrés sur PD2), ignorés sans le mod.
- Ce qui reste de PD2 dans la base : docs/internal/MODS-RESIDUEL.md (`npm run mods:residual`).
